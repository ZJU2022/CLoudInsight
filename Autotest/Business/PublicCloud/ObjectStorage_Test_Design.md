# 对象存储自动化测试设计思路

## 概述

本文档详细描述了对象存储产品线（UFile - Unified File Storage）的自动化测试设计思路，包括业务本质理解、功能点梳理、自动化交付产物设计、测试策略制定以及具体实施方案。对象存储是云服务中的核心存储服务，为应用提供海量、安全、高可用的对象存储能力，支持多种存储类型和访问方式。

## 第一步：业务本质与实例类型梳理

### 业务本质理解

#### 1. 什么是对象存储（UFile）
对象存储（UFile）是一种云存储服务，类似于网盘，但它是专门为应用程序设计的存储服务。用户可以通过API、SDK或管理工具上传、下载、管理文件，支持海量数据存储和高并发访问。

#### 2. 核心价值
- **海量存储**: 支持PB级别的数据存储，无容量限制
- **高可用性**: 数据多副本存储，99.999999999%的数据可靠性
- **多种存储类型**: 标准存储、低频存储、归档存储，满足不同成本需求
- **全球加速**: 支持CDN加速，提供全球访问能力
- **API友好**: 提供RESTful API和多种SDK，便于集成

### 实例类型分类

#### 1. 空间类型
- **单地域空间**: 数据存储在单一地域
  - 支持地域：北京、广州、上海二等
  - 适用场景：本地化应用、数据合规要求
- **全球化空间**: 数据跨地域复制
  - 支持地域：北京/广州/上海二
  - 适用场景：全球业务、就近访问

#### 2. 访问权限类型
- **私有空间**: 需要API密钥授权才能访问
  - 默认类型，安全性高
  - 适用于敏感数据存储
- **公开空间**: 可通过URL直接访问
  - 适用于公开资源，如网站图片
  - 支持CDN加速

#### 3. 存储类型
- **标准存储**: 高频访问数据
  - 访问延迟低，适合热数据
  - 成本相对较高
- **低频存储**: 低频访问数据
  - 访问延迟较高，适合冷数据
  - 成本较低
- **归档存储**: 长期保存数据
  - 访问延迟最高，需要解冻
  - 成本最低

#### 4. 地域覆盖
支持全球多个地域：
- 国内：北京、广州、上海二等
- 海外：香港、台北、东京、洛杉矶等

## 第二步：功能模块分类

### 1. 核心功能模块

#### 存储空间管理
- **创建存储空间**: 支持不同空间类型和存储类型
  - 存储空间域名：3-63字节，只能包含小写字母、数字、连接符
  - 首尾字符不能是短横线
  - 全局唯一，冲突时需更换名称
- **删除存储空间**: 支持资源清理
  - 删除前需清空所有文件
  - 删除后资源释放
- **修改空间类型**: 支持私有/公开切换
  - 私有→公开：所有人都可不通过身份验证访问
  - 公开→私有：所有访问操作需要身份验证
- **业务组管理**: 支持资源分组
  - 默认"未分组"
  - 支持选择和新建业务组

#### 文件管理
- **文件上传**: 支持多种上传方式
  - 单个/多个文件上传
  - 拖拽文件夹上传
  - 工具上传
  - 上传位置：当前目录、指定目录
- **文件下载**: 支持多种下载方式
  - 获取URL下载
  - 直接下载
  - 批量下载
- **文件操作**: 支持文件管理
  - 修改文件存储类型
  - 设置HTTP头
  - 删除文件（单条/批量）
  - 前缀查询
- **文件信息**: 显示详细信息
  - 文件名、ETag、文件大小
  - 存储类型、MIME-Type
  - 创建时间、更新时间

#### 域名管理
- **CDN加速**: 支持开启/关闭
  - 开启后支持全球加速
  - 状态支持刷新
- **自定义域名**: 支持绑定/解绑
  - 非CDN域名/CDN域名
  - 最多绑定20个域名
  - 支持域名管理操作

#### 镜像回源
- **回源规则**: 支持最多5条规则
  - 文件前缀配置
  - 回源地址配置
  - 自动从源站抓取文件
- **规则管理**: 支持增删改查
  - 添加回源规则
  - 编辑回源规则
  - 删除回源规则

### 2. 运维功能模块

#### 监控告警
- **监控指标**: 支持多种监控项
  - 流量监控：外网下载/上传流量、内网下载/上传流量
  - 存储监控：标准存储量、低频存储量、归档存储量
  - 请求监控：总上传/下载/删除请求数
  - 错误监控：5XX错误次数
  - 特殊监控：CDN回源流量、低频取回量、归档解冻量
- **时间范围**: 支持多种时间维度
  - 1小时、6小时、12小时、1天、3天
  - 自定义（最大支持15天）

#### 统计报表
- **报表维度**: 项目维度统计
  - 可选择地域、空间、时间
  - 默认状态：所有空间、近七天
- **时间范围**: 支持多种选择
  - 7天、15天、30天
  - 自定义时间范围
- **流量统计**: 支持闲时/忙时区分
  - 早上8点为分界点
  - 晚上0点为分界点
- **配额管理**: 支持配额包管理
  - 剩余配额查看
  - 历史购买配额统计

#### 令牌管理
- **令牌创建**: 支持细粒度权限控制
  - 令牌名称设置
  - 存储空间选择
  - 文件前缀授权
  - 权限勾选（读/写/删除）
  - 过期时间设置
- **令牌操作**: 支持完整生命周期管理
  - 查看/编辑令牌
  - 删除令牌
  - 搜索令牌
  - 刷新令牌列表

#### 其他服务
- **回调服务**: 支持事件通知
- **图片处理**: 支持多种图片操作
  - 基本图片信息获取
  - EXIF信息获取
  - 图片缩放、裁剪、旋转
  - 图片水印、格式转换
  - 管道顺序调用多种功能
- **AWS S3兼容**: 支持S3协议访问

## 第三步：自动化交付产物设计

### 自动化交付策略

#### 1. 基础功能回归 + 关联集合模板
- **限时要求**: 30分钟内完成
- **并行测试**: 支持多个工作流同时运行
- **智能回归**: 
  - 当前改动影响的功能：运行细分场景
  - 未影响的功能：正常回归测试

#### 2. 关联集合模板设计
- **基础回归验证**: 覆盖UFile基本功能
- **微服务覆盖**: 确保所有相关微服务正常启动
- **快速验证**: 发布时快速验证核心功能

#### 3. 回归测试工作流
设计六条核心工作流，根据发布可用区自动选择：
- 空间类型：单地域空间/全球化空间
- 访问权限：私有空间/公开空间
- 存储类型：标准存储/低频存储/归档存储
- 地域选择：根据测试需求选择

## 第四步：测试策略制定

### 测试分层设计

#### 1. 黑盒层测试
- **接口连续调用**: 模拟真实用户操作流程
- **文件操作场景**: 通过文件操作构造测试场景
- **异常场景设计**: 覆盖各种异常情况

- **数据一致性**: 确保数据在不同服务间的一致性
- **性能监控**: 监控关键性能指标

#### 3. 白盒层测试（较少）
- **代码分支覆盖**: 覆盖关键代码路径
- **权限控制逻辑**: 重点覆盖权限管理相关代码

#### 4. 平行层测试（例）
- **容灾自动化**: 
  - 存储空间故障测试
  - 网络连接中断测试
- **网络测试**: iperf打流测试
- **性能测试**: 
  - 文件上传下载性能测试
  - 并发访问性能测试
  - CDN加速性能测试
- **兼容性测试**: AWS S3协议兼容性测试

### 测试场景示例

#### 完整测试流程示例
```
CreateBucket → DescribeBucket → UploadFile → GetFileURL → 
DownloadFile → ModifyStorageType → SetHTTPHeaders → 
DeleteFile → DeleteBucket
```

#### 具体操作示例

**1. 创建存储空间**
```
- 选择空间类型：单地域空间/全球化空间
- 选择访问权限：私有空间/公开空间
- 选择存储类型：标准存储/低频存储/归档存储
- 输入存储空间域名：3-63字节，小写字母数字连接符
- 选择业务组：未分组/选择/新建
```

**2. 文件上传**
```
# 使用API上传文件
PUT /bucket-name/object-key
Content-Type: application/octet-stream
Authorization: UCloud xxx

# 使用SDK上传文件
ufile.put_file('bucket-name', 'object-key', 'local-file-path')

# 使用管理工具上传
- 选择文件
- 选择上传位置
- 选择存储类型
- 点击上传
```

**3. 文件下载**
```
# 获取文件URL
GET /bucket-name/object-key
Authorization: UCloud xxx

# 直接下载文件
wget "https://bucket-name.region.ufileos.com/object-key"

# 使用SDK下载
ufile.get_file('bucket-name', 'object-key', 'local-path')
```

**4. 权限管理**
```
# 创建令牌
- 令牌名称：test-token
- 存储空间：test-bucket
- 文件前缀：test/
- 权限：读/写/删除
- 过期时间：2024-12-31

# 使用令牌访问
Authorization: Bearer token-string
```

**5. 监控查询**
```
# 查询监控数据
GET /metrics
Parameters:
- BucketName: test-bucket
- MetricName: DownloadTraffic
- TimeRange: 1h
```
